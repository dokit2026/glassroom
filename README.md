# GLASSROOM

最新版のWebゲーム一式です。ビルドやnpmのインストールは不要です。

## GitHubにアップする
1. このZIPを展開します。
2. 展開した中身を、フォルダー構成を保ったままGitHubのリポジトリにアップロードします。
3. index.htmlが公開フォルダーの直下になるように、GitHub Pagesで公開します。
4. 公開されたURLから開いてください。

ZIPそのものをアップするだけではゲームは動きません。materialsフォルダーも必ず一緒にアップしてください。
index.htmlのダブルクリックではJavaScriptモジュールの読み込みが制限されるため、HTTPサーバーまたは公開URLで開いてください。
ローカルで試す場合は、このフォルダーで python -m http.server 8000 を実行し、http://localhost:8000/ を開けます。

## 操作
- OPEN：コンパクトを開く
- もう一度クリック：部屋に入る
- ドラッグ：360度見回す
- WASDまたは画面のスティック：移動
- ガラスをクリック：解答
- 出現したアイテムをクリック：音を鳴らす

音は最初のOPENクリックで有効になります。
完成順位とニックネームは、同じPC・同じブラウザ・同じ公開先のlocalStorageに保存されます。
公開先のURLが変わるとランキングは引き継がれません。ブラウザの保存データを削除すると記録も消えます。
端末をまたぐ共有ランキングではありません。

## ファイル
- index.html：画面
- style.css：スタイル
- app.js：3D表示・操作・進行
- items.js：家具やアイテムの3Dモデル
- glass-patterns.js：ガラスの凹凸
- audio.js：効果音
- ranking.js：タイム・順位・保存
- materials/：マテリアル素材
- three.module.js：同梱のThree.js r170（MIT License）

素材とライブラリは同梱されており、外部CDNの読み込みは不要です。
ゲーム進行・保存などの処理は確認済みですが、実際の3D表示と音の聞こえ方は展示PCで確認してください。
